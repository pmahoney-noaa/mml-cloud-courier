## Live-fire finding and fix (commit 662d57a on master)

**Packaged service died at start with service-specific 0x20000001.** Event
log: `SvcDoRun → ServiceHost.__init__ → uvicorn Config.configure_logging →
dictConfig → ValueError: Unable to configure formatter 'default'`, chained
from `uvicorn.logging.DefaultFormatter.__init__` calling
`sys.stdout.isatty()` on `None`. Root cause: an SCM-launched PyInstaller exe
has no console and the bootloader leaves `sys.stdout`/`sys.stderr` as `None`;
the venv-hosted `python.exe` always provided stream objects, which is why
five months of venv service operation never hit it. Reproduced in-venv by
setting `sys.stdout = None` before `uvicorn.Config(...)`. Fix: `SvcDoRun`
now calls `_ensure_service_stdio()` — devnull streams when stdio is None —
before hosting. Two regression tests added. Note for posterity: Windows' NUL
device reports `isatty() == True` (character device); harmless, colors are
discarded.

## Environment notes

- Inno Setup 6.7.3 installed **user-scope** via winget during the round; the
  build script probes machine- then user-scope ISCC paths.
- The gate's step 4/6 sequencing surfaced the stdio defect precisely because
  the packaged smoke (step 2) can only prove dispatcher reachability (1063),
  never a real `SvcDoRun` — an SCM start is the first time host construction
  runs frozen. Future packaged changes to service startup should expect the
  first REAL verification to be a live SCM start.
- Deferred (final-review triage, in plan/ledger history): sc start exit code
  unchecked in the .iss; `find "STOPPED"` locale-bound; ssDone reminder
  wording over-alarms on the update path; `_grant_readers` `check=True` on
  malformed hand-added SIDs; `[Files]` overlay without `[InstallDelete]`
  (stale-payload hazard on future dependency removals); CLI uvicorn
  hiddenimports immaterial; version_info PEP 440 pre-release limitation.
